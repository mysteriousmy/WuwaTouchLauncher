# 0.5 界面与平台行为

采用 Avalonia 12.1.4 与 AtomUI 6.2.7。窗口使用原生 Wayland（可回退 X11）
或 Windows 后端，图形与字体原生库静态链接到 NativeAOT 主程序中。

## 信息架构

- **启动游戏**：普通 / 触控两个模式卡片，安装位置或 Lutris 来源，
  资源画质、DirectX、基础画质和开场动画。
- **触控画质**：56 项设置，分类与跨分类搜索，清楚显示已调整数量；帧率解锁单独选择，默认关闭。
  设置名称与帮助为主，底层参数放在悬浮提示中。
- **输入与热键**：鼠标过滤、快捷键和当前会话操作。
- **设置**：当前来源适用的附加参数、快捷入口、配置与日志。

侧栏保持稳定；底部固定保存、预览和启动动作。页面使用深灰蓝底色、蓝色强调、
一致的线性图标、12px 圆角和明确的字体层次。页面按需创建，编辑立即进入草稿，
切页与切模式不丢失输入；保存仍走现有原子写入流程。

## 显示与生效条件

| 当前来源 | 用户可以编辑 | 隐藏并不参与启动的手动值 |
|---|---|---|
| Windows | 游戏位置、游戏参数、两种模式与触控选项 | 全部 Linux / Lutris / Wine / Proton / UMU 配置 |
| Linux，Lutris 条目生效 | 条目选择、两种模式与触控选项 | 手动路径、运行器类型、前缀、附加参数、前置命令、环境变量与 UMU 路径 |
| Linux，手动来源或自动检测无 Lutris | 游戏位置、运行器、前缀、附加参数与 Linux 环境 | 无 |

隐藏的手动值保留在配置中，切回手动来源可继续使用。Lutris 模式从条目读取其
附加参数、运行器、前缀和环境，启动器专属的模式及图形选项仍按用户选择应用。

## Windows 安装检测

读取 HKCU / HKLM 的 32 / 64 位卸载记录、库洛 KRLauncher 安装记录及资源目录缓存、
Steam 安装库和 Epic 安装清单。只接受实际存在的
`Client/Binaries/Win64/Client-Win64-Shipping.exe`，合并重复位置，跳过损坏或失效的记录。
不遍历磁盘。单一安装可以自动填入；多个安装由用户选择；有效的已保存或手选路径
不被重新扫描覆盖；没有结果时保留文件选择入口。

文件选择同样可以接受官方启动程序所在目录，并解析出实际的游戏主程序。
检测不会启动官方启动器、写注册表或改动安装清单。

格式依据：
[库洛安装缓存格式](https://github.com/B1ngFeng/wuwa-launcher-path/blob/main/docs/format.md)；
[现有安装记录读取实现](https://github.com/ok-oldking/ok-wuthering-waves/blob/master/config.py)。
